# Yogeshwari Dairy Inventory - Android APK Setup & Build Guide

This document details the architecture, configuration, build steps, and release workflows for converting the Yogeshwari Dairy ERP/POS React application into a native Android APK using **Capacitor 8**.

---

## 1. Architecture Overview

### Bundled Native Architecture (Recommended & Implemented)
- **Local Asset Bundling:** All compiled web assets (`dist/` generated by Vite) are bundled directly inside the APK (`android/app/src/main/assets/public/`).
- **Zero Web Latency on Launch:** The application loads instantly from device storage without requiring an initial network round-trip to Vercel.
- **Hosted Cloud Backend:** The app connects directly over secure HTTPS/WSS to **Supabase** (PostgreSQL, GoTrue Auth, Realtime) and hosted backend endpoints.
- **Native Hardware Access:** Direct bridge to device camera (ZXing + Google ML Kit Barcode Detector), native Android share dialog, hardware back-button listener, network status watcher, and status bar controls.
- **Production Web Coexistence:** The existing Vercel deployment (`https://yogeshwari-dairy-shop.vercel.app/`) remains 100% operational and untouched.

### Why NOT a Remote WebView Shortcut?
A "remote WebView" simply points an app shell to a live URL (`https://...`). We avoid this because:
1. **Google Play Rejection:** Google Play Policy (Minimum Functionality) often rejects pure website wrappers.
2. **Offline Fragility:** If internet connectivity drops, the remote app shows a white screen or browser connection error.
3. **Hardware Latency:** Remote WebViews have restricted or sluggish camera access and cannot guarantee offline caching of assets.
4. **App Store Versioning:** In a bundled app, offline cash transactions and inventory lookups work reliably even in rural areas with spotty network coverage.

## 3. Installed Native Plugins & Purpose

1. **`@capacitor/app`**
   - Intercepts native Android hardware/gesture back-button.
   - Closes active modals and navigation drawers.
   - Prevents accidental exit via double-tap confirmation prompt.
2. **`@capacitor/camera`**
   - Manages runtime camera permissions on Android 6.0+.
   - Ensures barcode scanner camera stream is never blocked by permission denial.
3. **`@capacitor/filesystem` & `@capacitor/share`**
   - Writes generated PDF reports (Profit & Loss, Invoices, Khata statements) and CSV spreadsheets to device cache.
   - Triggers native Android Share sheet (WhatsApp, Gmail, Google Drive, Save to Files).
4. **`@capacitor/keyboard`**
   - Handles soft keyboard appearance without covering billing input fields.
   - Configured with `android:windowSoftInputMode="adjustResize"`.
5. **`@capacitor/network`**
   - Instant native detection of Wi-Fi / cellular disconnection and reconnection.
6. **`@capacitor/status-bar`**
   - Sets dark emerald status bar styling (`#0B1210`) matching the brand identity.
7. **`@capacitor/splash-screen`**
   - Displays authentic Yogeshwari Dairy splash screen on boot while assets initialize.

## 5. Prerequisites for Building the APK

To build the native APK on your computer, install the following:

1. **JDK (Java Development Kit) 17 or 21:**
   - Download: [Eclipse Adoptium Temurin 17 / 21](https://adoptium.net/) or Microsoft OpenJDK.
   - Set environment variable `JAVA_HOME` pointing to your JDK directory (e.g., `C:\Program Files\Eclipse Adoptium\jdk-17...`).
   - Add `%JAVA_HOME%\bin` to your `PATH`.
2. **Android Studio:**
   - Download & install [Android Studio](https://developer.android.com/studio).
   - In Android Studio SDK Manager, install:
     - Android SDK Platform (API 34 or API 35)
     - Android SDK Build-Tools
     - Android SDK Command-line Tools

## 6. Building the Debug APK

### Option A: Using Command Line (Quickest)
Once Java and Android SDK are set up:
```bash
# 1. Build web production bundle and sync Capacitor
npm run cap:sync

# 2. Navigate to android directory
cd android

# 3. Build Debug APK using Gradle wrapper
# On Windows (PowerShell or CMD):
.\gradlew.bat assembleDebug

# On macOS/Linux:
./gradlew assembleDebug
```

The generated APK will be available at:
`android/app/build/outputs/apk/debug/app-debug.apk`

### Option B: Using Android Studio (Visual GUI)
```bash
# 1. Sync assets
npm run cap:sync

# 2. Open Android Studio
npx cap open android
```
Inside Android Studio:
1. Wait for Gradle sync to complete in the bottom status bar.
2. Go to **Build** menu > **Build Bundle(s) / APK(s)** > **Build APK(s)**.
3. Once completed, a notification pops up with a **locate** link to the `app-debug.apk`.

## 7. Generating a Production Signed Release APK

To create a signed APK ready for installation on shop tablets and phones:

### Step 1: Generate a Keystore (One-Time)
Run this command in terminal (fill in your secure password):
```bash
keytool -genkey -v -keystore yogeshwari-release.keystore -alias yogeshwari -keyalg RSA -keysize 2048 -validity 10000
```

### Step 2: Configure Signing in `android/app/build.gradle`
Add signing credentials to `android/app/build.gradle`:
```groovy
android {
    ...
    signingConfigs {
        release {
            storeFile file("../../yogeshwari-release.keystore")
            storePassword "YOUR_STORE_PASSWORD"
            keyAlias "yogeshwari"
            keyPassword "YOUR_KEY_PASSWORD"
        }
    }
    buildTypes {
        release {
            signingConfig signingConfigs.release
            minifyEnabled false
            proguardFiles getDefaultProguardFile('proguard-android.txt'), 'proguard-rules.pro'
        }
    }
}
```

### Step 3: Build Signed Release APK
```bash
cd android
.\gradlew.bat assembleRelease
```
The output signed APK will be created at:
`android/app/build/outputs/apk/release/app-release.apk`

## 8. Web vs. APK Deployment Lifecycle

| Change Type | Vercel Web Deployment | Android APK Installation |
| :--- | :--- | :--- |
| **Deployment Trigger** | `git push origin main` | Build new APK and install on phone |
| **UI / Styling updates** | Instant on page reload | Requires `npm run cap:sync` + APK rebuild |
| **Supabase Data & Inventory** | Realtime shared database | Realtime shared database (instant across web & app) |
| **New Native Plugin Addition** | N/A (Web only) | Requires APK rebuild |

## 🚀 How to Run in Supabase SQL Editor

1. Open your **Supabase Dashboard** -> **SQL Editor**.
2. Click **"+ New Query"**.
3. Copy all lines from [`parle/instock.sql`](file:///d:/Projects/Yogeshwari%20Dairy%20Shop%20Inventory%20System/parle/instock.sql) (or paste the code provided).
4. Click **"Run"** (or press `Ctrl + Enter`).
5. All 34 Parle products will be added to `products` and `batches` with active FEFO tracking, and Supabase will output a verified in-stock summary table.
